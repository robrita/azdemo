# Placeholder Guide

Replace the following values when copying this template into a new repository:

- Project name strings such as `template-fullstack` and `Template Merchant Hub`.
- Cosmos database name and container naming if your domain differs.
- Frontend copy, logo treatment, and navigation labels.
- Any sample domain entity names such as `merchant`.

Do not replace the architectural seams, health probes, hosting adapters, or config model just to fit naming preferences.
