# SharePoint Logic Apps Workflows

This repository contains Azure Logic App workflow definitions for SharePoint automation, located in the `sp-flows/` folder:

- **sp-chunks.json**: Handles chunked file operations for SharePoint.
- **sp-ingestion.json**: Automates data ingestion from SharePoint.
- **sp-onFileDelete.json**: Triggers actions when files are deleted in SharePoint.
- **sp-onFileUpdate.json**: Triggers actions when files are updated in SharePoint.
- **sp-pages.json**: Manages SharePoint page operations.

Each workflow is designed for specific SharePoint integration scenarios. See individual JSON files for details.
